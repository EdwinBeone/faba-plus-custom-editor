# Politique de sécurité

Merci de ne pas publier publiquement une vulnérabilité permettant la lecture ou l'écriture arbitraire de fichiers.

Utilisez la fonction **Report a vulnerability** de GitHub si elle est disponible sur le dépôt, ou contactez le mainteneur via son profil GitHub. Incluez une reproduction minimale sans données personnelles, clés ni fichiers audio protégés.

Les erreurs de format sur une carte de test peuvent être ouvertes comme issues publiques. Faites toujours une copie de la carte avant de reproduire un problème d'écriture.
